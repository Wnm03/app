REAL UI FINDINGS AND ROOT CAUSES
--------------------------------
1) [DEV] smoke-test banner covered the top application chrome.
   Root cause: modules/shared/smoke-test.js positioned the diagnostic banner fixed at top:0,
   covering the sticky header and its Backup/title area.
   Fix: move the diagnostic surface to the lower non-critical area above bottom navigation;
   make message wrapping safe; make close control a real 44x44 touch target.
   Production behavior: smoke-test remains gated by its existing dev-mode detection; this
   patch does not remove diagnostic capability. The visual overlap is eliminated.

2) Car Notes mobile overflow.
   Root cause: nested layout children could retain intrinsic width; several responsive rules
   existed but were not consistently applied to all direct children/content blocks.
   Fix: scoped min-width/max-width containment and safe wrapping for Car Notes headings,
   summaries, metrics and descriptive content. Intentional inner horizontal scrolling for
   list/tab containers is preserved; no global overflow-x:hidden workaround was introduced.

3) AI mobile overflow.
   Root cause: chat/content children did not have a complete intrinsic-width contract,
   especially long AI/chat content and the input row.
   Fix: scoped min-width/max-width rules, long-content wrapping, bounded chat bubbles,
   bounded input row/input, and a 44x44 send button.

4) Settings touch targets.
   Root cause: compact controls such as card-setting actions, collapse toggles and switches
   exposed hit areas below the desired mobile touch target size.
   Fix: scoped #page-settings hit-area hardening to >=44px while keeping visual density compact;
   toggle track remains visually compact inside the larger hit area.
