-----------------------
The originally-shipped patch-S1841-fuel-data-quality-forecast-cumulative-S1840.zip
was built against a plain app-main(29) source tree that did NOT include the prior
S1840 service-crash fix (Servis.itemsOfGroup / ServisChecklist.itemsOfGroup helper
in servis-checklist.js / servis.js / tx-servis.js). Its prebuilt app-bundle-a/b.min.js
therefore silently reverted that fix once applied on top of an already-patched tree:
source .js files still had the fix, but the shipped bundle did not contain
"itemsOfGroup" at all. This tripped tests/s1840-release-gates.test.js
("S1840 production version contract has no stale v1817 runtime references").
